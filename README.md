Cookie-Consent-Banner
A simple and responsive cookie consent banner built using HTML, CSS, and JavaScript. This project demonstrates how to handle user consent and store preferences using localStorage.

Live Demo - 


## 🚀 Features
- Modern and clean UI
- Accept / Decline cookie options
- Stores user preference in browser (localStorage)
- Reset cookie preferences button
- Fully responsive design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📂 Project Structure
│── index.html
│── style.css
│── script.js


## ⚙️ How It Works
- When the user clicks **Accept All**, consent is stored in `localStorage`
- When the user clicks **Decline**, cookies are disabled
- The banner will not show again unless reset
- The **Reset Cookie Preferences** button clears stored consent
